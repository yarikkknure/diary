## Опис програми

**Щоденник** — настільна програма-планувальник запланованих заходів з графічним інтерфейсом (Windows Forms).

### Функціональні можливості

| Функція | Опис |
|---------|------|
| Додавання заходу | Назва, дата, час початку, тривалість (хв), місце, нотатки |
| Автоматичне нагадування | Показ найближчого заходу у шапці вікна; оновлення щохвилини |
| Перегляд за датою | Фільтри: Всі / Сьогодні / Завтра / Позавтра / будь-яка дата |
| Аналіз накладок | Виявлення заходів, що перетинаються за часом |
| Очищення минулих | Видалення або перенесення минулих заходів на N днів уперед |
| Зберігання даних | JSON-файл у папці «Документи» (`diary_events.json`) |

## Технічний стек

- **Мова:** C# 13
- **Платформа:** .NET 10
- **UI:** Windows Forms (WinForms)
- **Зберігання:** JSON (`System.Text.Json`)
- **Архітектура:** Repository Pattern + Service Layer

## Структура проєкту

```
Diary/
├── DiaryEvent.cs           # Модель заходу (дата, час, тривалість, місце)
├── IEventRepository.cs     # Інтерфейс репозиторію
├── JsonEventRepository.cs  # Реалізація: зберігання у JSON-файлі
├── DiaryService.cs         # Бізнес-логіка (нагадування, накладки, очищення)
├── MainForm.cs             # Головне вікно програми
├── EventForm.cs            # Форма додавання / редагування заходу
├── Program.cs              # Точка входу
└── Diary.csproj            # Файл проєкту (.NET 10, WinForms)
```

## Діаграма класів (спрощена)

```
DiaryEvent ◄──── IEventRepository ◄──── JsonEventRepository
                        ▲
                        │
                  DiaryService
                        ▲
                        │
              MainForm ──── EventForm
```

## Алгоритм виявлення накладок

Два заходи вважаються такими, що **перетинаються**, якщо виконується умова:

```
StartA < EndB  AND  EndA > StartB
```

де `EndX = StartX + DurationX`.
